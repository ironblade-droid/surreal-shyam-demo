# Surreal Shyam · interactive 3D demo

Lead Setu demo for **Surreal Shyam**, a premium 3 BHK project in Udaipur.

- 3D model of the building: pick a floor, then a wing
- Floor plans and area cards (SBU, built-up, carpet, balcony) from the builder's brochure
- 360° tour of the **1st Wing** (living, kitchen, three bedrooms, toilet, balcony)

Live: https://ironblade-droid.github.io/surreal-shyam-demo/

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview  # http://localhost:4174
```
